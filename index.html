CORS proxy

Some endpoints (e.g. Claude's subscription usage endpoint) block direct browser requests. Point this at your own Cloudflare CORS proxy Worker and blocked requests will be routed through it instead. Protect it with a shared secret instead of Cloudflare Access: Access sits in front of the Worker and rejects every CORS preflight (OPTIONS) before the Worker ever runs, since browsers never send credentials on a preflight — on a plain *.workers.dev domain there's no way to carve out an exception for that. Set PROXY_TOKEN as a Worker secret (wrangler secret put PROXY_TOKEN) and paste the same value below; it's sent as an X-Proxy-Token header and checked by the Worker itself, which always answers OPTIONS without needing it.
